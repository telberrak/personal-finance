# Aide

## Que signifie « Disponible » ?

Le solde de vos comptes courants, moins les factures encore dues avant la prochaine paie, moins l’épargne mise de côté. Réparti sur les jours restants, il indique à peu près ce que vous pouvez dépenser chaque jour.

## Comment ajouter une transaction ?

Touchez **+** (ou **Ajouter une transaction** sur ordinateur). Ledger propose une catégorie d’après vos règles, votre historique et les enseignes connues. Joignez la photo d’un reçu et Ledger peut en lire le montant et la date.

## Comment fonctionnent les factures ?

Ajoutez prélèvements, virements permanents et abonnements dans **Factures**. Les paiements y sont rapprochés automatiquement, les hausses de prix signalées, et un rappel arrive la veille de chaque échéance. Les paiements réguliers qui ne sont pas encore des factures sont suggérés.

## Puis-je importer mon relevé bancaire ?

Oui : **Importer** lit les fichiers CSV de la plupart des banques françaises et britanniques. Les doublons sont ignorés et les paiements rapprochés des factures. Avec la synchronisation, vous pouvez aussi connecter une banque dans **Réglages → Connexions bancaires**.

## Comment utiliser Ledger sur plusieurs appareils ?

Activez **Réglages → Synchronisation et appareils**. Connectez-vous avec un code reçu par e-mail, puis enregistrez votre **clé de récupération** : elle est nécessaire pour ajouter un autre appareil. Vos données sont chiffrées avant de quitter l’appareil.

## J’ai oublié mon code

Le code chiffre vos données sur cet appareil : il ne peut pas être réinitialisé. Déverrouillez avec une clé d’accès si vous en avez ajouté une. Sinon, effacez les données de ce site dans votre navigateur et restaurez une sauvegarde, ou reconnectez-vous à la synchronisation avec votre clé de récupération.

## Comment protéger mes données ?

Téléchargez régulièrement une sauvegarde (**Réglages → Sauvegarde**), de préférence avec un mot de passe. Utilisez un code ou une clé d’accès, et **Masquer les montants** quand d’autres peuvent voir votre écran.

## Puis-je partager avec mon conjoint ?

Oui : **Réglages → Foyer**. Invitez-le avec un lien et choisissez les comptes à partager. Le reste reste privé. Pour partager des frais entre amis, utilisez **Amis**.

## Langues et devises

Choisissez le français, l’anglais ou l’arabe et votre devise dans **Réglages → Langue et devise**. Chaque compte peut avoir sa propre devise ; les totaux sont convertis dans votre devise principale.
